Which address?

The address of the computer that runs the rune server, including its port (4545 unless you changed it, or the HTTPS port your Tailscale Serve uses).

  • Tailscale: the PC's full https name; rune is then reachable anywhere, encrypted.
  • Home Wi-Fi only: the PC's LAN address over http. iOS allows plain http for local addresses only.
