Inter and Source Serif 4 (latin subsets, variable weight) are the web UI's fonts (@fontsource-variable/inter and
@fontsource-variable/source-serif-4) decompressed from woff2 with `woff2_decompress`, because GPUI reads TrueType and
OpenType, not woff2. Licences: LICENSE-Inter.txt, LICENSE-Source-Serif-4.txt (SIL Open Font License).
IBM Plex Mono is rune mini's own face (LICENSE-IBM-Plex-Mono.txt).
